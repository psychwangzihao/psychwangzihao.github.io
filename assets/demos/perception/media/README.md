# media/ — 需要你自己放进去的文件

这个文件夹本来是空的。网页在没有这些文件时**不会报错**，会自动降级到备用画面；
把文件按下面的文件名丢进来，网页会自动使用它们，不用改任何代码。

| 文件名 | 用在哪 | 说明 |
|---|---|---|
| `mcgurk.mp4` | 场景 3 · McGurk 效应 | 一段 16:9 的 McGurk 视频（画面发 /ga/、声音是 /ba/）。没有它时，场景 3 会显示一个自绘的动画口型。1080p、5 MB 以内为宜（部署脚本会静默丢弃 ≥5 MB 的文件）。 |
| `qr-ask.png` | 场景 10 · 求索卡 | 左边那个二维码，「匿名提问」。建议正方形、≥ 400×400 px。 |
| `qr-learn.png` | 场景 10 · 求索卡 | 右边那个二维码，「想继续学习」。 |

## McGurk 视频从哪来

公开的学术演示片段（例如 BBC 那期著名的 McGurk 片段，或各认知心理学教材配套的视频）
可以自行截取；注意版权，课堂使用一般没问题，但不要公开再分发。

## 生成二维码

任意二维码生成器都行，内容分别填：

- `qr-ask.png` → 匿名提问的问卷/表单链接（腾讯问卷、金数据、问卷星……）
- `qr-learn.png` → 你想推荐给学生的科普资源链接（公众号、书单、网站……）

生成后直接放进这个文件夹，文件名必须是上面这两个。
