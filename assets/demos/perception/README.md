# 眼见为实吗？ / Is Seeing Believing?

於潜中学心理学科普讲座的交互式演示。14 个场景、65 个状态，
不是幻灯片 —— 每一幕是一个可以动手玩的小实验。

- 线上地址：<https://psychwangzihao.github.io/demos/perception/>
- 直接访问静态包：`/assets/demos/perception/`

**不需要任何外部素材**：校徽和院系标识已经打进 `media/`，其余全是代码画的
（SVG / Canvas），没有视频、没有二维码、没有需要打印的东西。

## 现场怎么用

开场是两扇合拢的浙大蓝幕布，中间一枚校徽 —— **点一下校徽开始上课**，
幕布向两侧滑开，露出标题。最后下课的时候幕布再合拢，回到同一枚校徽。

| `←` | 上一状态 |
| `↑` / `↓` | 上一 / 下一场景 |
| `1`–`9` | 跳到第 1–9 个场景 |
| `0` | 跳到「收束」那一幕 |
| `Home` | 回到开场 |
| `B` | 黑屏（临时遮挡，再按恢复） |

| `?` | 显示快捷键提示 |

链接可以带参数直接跳到某处，方便排练：

### 时间不够时砍哪几幕

必讲：`title` → `illusion` → `tree` → `blindspot` → `aphantasia` →
`stratton` → `eeg` → `closing` → `awe` → `curtain`（约 35 分钟）

可跳：`brain`（只放 `brain.0` 给大家看一眼那张图；`brain.3` 的平衡觉活动
也可以跳）、`eagleman`、`bci`（只放 `bci.0` 和 `bci.2`）。
两个「先猜一猜」（`stratton.0`、`eagleman.0`）各只要 20 秒，
但如果时间紧，直接按 → 两次就能越过（第一次揭晓、第二次翻页）。

### 几处需要留意的地方

- **`tree` 里有两次统计**（1.1 和 1.3），两次共用同一组数字，**第二次为准**。
  第 11 幕的回扣句会自动判断：**只有「不会响」占多数时才说「我们当时说：不会响」**，
  否则改说「我们当时投出来的，是「会响」」。所以你怎么投都不会露馅，
  但**两次都要真投**，回扣才有东西。
- **`aphantasia.0 → 1`** 是「闭眼想象 → 睁眼举手」。举完手环顾全场的那一下
  是这一幕的重点，别急着按下一张。
- **`brain.3`** 会让全场站起来单脚站 10 秒。前面连着三幕都在坐着听，这里换口气。
- **`illusion` 是冷开场，别跳过。** 全班先亲眼看一次「自己的眼睛在骗自己」，
  后面所有道理才有落点。用的是艾宾浩斯错觉：两个蓝圆**半径完全相同**，
  只是周围一圈圆的大小不同。**第二拍才是重点** —— 橙圈把「一样大」演示出来之后，
  再看一眼，它们还是不一样大。`eeg.4` 会把这句接回来。
  （原来用的是闪烁网格，那属于「周边视觉」类错觉，对屏幕和距离都敏感，
  现场看不出来，已换掉。）**注意它现在不在开场，而是排在 Eagleman 之后**：
  它的落点是「知道真相也不能让错觉消失 → 所以『我看到』不能当证据」，
  正好接上脑电那一幕的「科学不是猜，是测量」。
- **`blindspot` 后排怎么办**：投影仪上这个实验对后排是无效的（离屏幕太远，
  两点间距需要拉到一米以上）。所以那一幕额外给了「用自己两根拇指做」的做法
  （`#bsHands` 那张卡），全场都能做，不依赖屏幕。
- **`closing` 原来那一屏「求索卡」已经去掉**（要印卡片 + 两个二维码）。
  「有问题，来教室外面找我」这句挪到了第 12 幕的幕布上。

## 怎么加一个新场景

1. 写 `s13_xxx.js`（照抄 `s01_tree.js` 的结构）：

```js
PERCEPTION.css('scene-xxx', `/* 这个场景专属的 CSS */`);

PERCEPTION.scene({
  id: 'xxx',
  label: '场景名',
  noClick: false,      // true = 禁止「点空白处前进」
  dark: false,         // true = 暗色背景（也可以给状态元素加 data-dark）
  states: [
    function (ctx) {
      ctx.set(`<h1 class="hero anim">你好</h1>`);
      ctx.after(2000, () => ctx.next());
    },
  ],
});
```

2. 在 `index.html` 里加一行 `<script src="./s13_xxx.js"></script>`（顺序就是场景顺序）。

`ctx` 提供 `set / add / q / qa / on / each / raf / frame / after / every / soon /
wordby / stagger / autoNext / holdNext / next / prev / goto / toast`，
**所有监听器、定时器、动画帧都会在切换场景时自动清理**，
所以来回跳不会泄漏。详细说明见 `core.js` 顶部的注释。

### ⚠️ 每一屏「进来时」都必须是一个完整的画面

`.step` 元素虽然藏着，**但它的版面还在**。所以如果一屏里所有内容都是
`.step`，进来就是一大片空白 —— 讲者和学生都会以为「内容丢了」。

**规则**：`.step` 只留给**唯一那句不能提前泄露的答案**；
一屏的主内容必须进来就看得见（可以错开进场）。
写完之后用下面这段检查（它会逐屏报告进来时有多少可见文本）：

```
node /tmp/blankcheck.js      # 脚本在 /tmp，需要时重建
```

判断标准：`可见文本 = 0` 且这一屏没有图形（SVG/图）→ 就是空白屏，必须修。
2026-09-15 用这个查出并修掉了 7 屏（盲点×2、心盲、错觉、脑电、回响、树倒）。

### 节奏：默认「按一次出一行」，不要自动播

`ctx.steps()` 把一个状态里的内容拆成「按一次出一行」：带 `.step` 的元素
默认藏着，每按一次露一行，全部露完之后再按才翻页。

```js
ctx.set(`<p class="step">第一句</p><p class="step">第二句</p>`);
ctx.steps();
```

**它的意义是节奏权在讲者手上**：想停多久停多久，也不会因为手快把还没讲的
内容翻过去。凡是「讲者需要先说两句再揭晓」的地方，都用它，不要用
定时器自动出现，更不要 `ctx.autoNext()`。

**这个 demo 里几乎不该有自动翻页。** 原来有几处倒计时（盲点 20 秒、
心盲症 10 秒、平衡觉 10 秒）都已经去掉了 —— 现场由讲者控制节奏。

### 科学精神那一节：要举例，不说教（`eeg` 8.4–8.6）

这是全场唯一讲「科学方法」的地方，也是用户最在意的一段。原来写的是
「脑电不是读心术 / 要基线要控制要重复要统计」——那是口号，学生听不进去，
而且有说教味。**说教感来自没把话讲明白**，所以改成「先摆四句流传很广的话，
再一句一句给具体、可查的回答」：

| 说法 | 回答 | 依据 |
|---|---|---|
| 人类只用了大脑的 10% | 如果九成闲着，切掉它应该没事；可临床上任何一块脑区受损都带来对应功能丧失，发呆时全脑也在耗能 | 神经心理学常识 |
| 左脑理性 / 右脑感性 | 胼胝体几亿根纤维，稍复杂的事两边都参与；这说法来自六十年代对**切断胼胝体病人**的研究，被简化得完全走样 | — |
| 心理学就是算命 | 占卜没法被证伪；**MBTI** 隔五周重测，约一半的人会换掉至少一个字母 | McCarley & Carskadon (1983)；Pittenger (1993) |
| 你能读出我在想什么 | 靠表情和身体语言判断说谎，**206 项研究 / 24,483 人**的汇总准确率是 **54%**；**受过训练的警察和法官并不比普通人更准** | Bond & DePaulo (2006), *Pers. Soc. Psychol. Rev.* |

收在「每一条错的，都不是『想错了』，而是『没测过』」→「科学不是猜，是测量。」
8.6 再回应那句「学心理的是不是都有病」：心理学的对象是人自己，
所以每个人都觉得自己有资格评论 —— **物理学就没有这个待遇**；
这不是它不科学的原因，恰恰是它难的地方。

**面向高中生要按「有独立思考能力的人」来写，不是按「听什么就是什么的人」。**
泛泛地扣「伪科学」的帽子没有说服力，给实例和数字才有。

### ⚠️ 一屏里只要有 `.step`，就**必须**调 `ctx.steps()`

否则那一屏的 `.step` 永远不显示，**而且按一下 → 会直接跳到下一幕**
（因为没有任何东西拦住它）—— 这就是「跳页」。

2026-09-15 用下面这段扫出过两处漏网的（`closing` 的两屏）：

```bash
cd assets/demos/perception && python3 - <<'SCAN'
import re, glob
for f in sorted(glob.glob('s*.js')):
    src = open(f).read()
    m = re.search(r'states:\s*\[(.*)\n  \],\n\}\);', src, re.S)
    if not m: continue
    for st in re.split(r'\n    /\* ---- ', m.group(1))[1:]:
        if len(re.findall(r'class="step', st)) and 'ctx.steps()' not in st:
            print('漏了:', f, st.split(' ----')[0][:40])
SCAN
```

### 「心在哪里」那一幕：心脏中心说

`mind` 有 5 个状态，内容取自作者 2050 大会的讲稿《心在哪里》
（`~/Documents/2050大会&未来人类/新生论坛/心在哪理.docx`）：

1. 「心里想」「心里难受」→ 可是「心」在哪里呢？
2. **心脏中心说**：思考会发热，心脏把滚烫的血送到大脑，大脑的褶皱是**散热片**
3. 它为什么有说服力：完美自洽 + 符合日常经验（紧张心跳加速、伤心胸口发闷、
   没心脏就什么都没了）
4. **数据反驳**：思考时心脏放电几乎不变、大脑天差地别；
   阿尔茨海默病患者的心脏和同龄人无异，大脑却出现大量空洞
5. 收束：**心理学能从哲学独立出来，正因为它不再只跟「日常经验」讲道理，
   而是跟数据讲道理** —— 否则会永远困在那套完美的「散热片」逻辑里

这一幕其实是全场的论点预演：**眼见为实吗 → 所以要测量。**

### 爱因斯坦的例子（`eeg` 8.8）

「把大脑拿出来看」那一段取自作者杭二中的课程讲稿。事实核对过：

- 1955 年爱因斯坦在普林斯顿去世，病理科主任**托马斯·哈维私自保留**了大脑，
  切成约 240 块泡在福尔马林里，私藏 43 年，引起巨大争议
- 1985 年**戴蒙德（Marian Diamond）**报告左侧顶叶胶质细胞比例更高，引发轰动
- **但对照组 11 人平均 64 岁，爱因斯坦 76 岁**；胶质细胞随年龄继续分裂，
  比例偏高也可能只是神经元老死更多。戴蒙德本人也承认有局限
- 讲稿里那句 **「先射箭，再画靶」** 是这一幕的落点：
  **只有一个样本，又在事后反复找，找到什么都不奇怪**

紧接着 8.9 才是人脑库（七百多例）—— 顺序是「一个不够 → 所以要很多个」。

### 错觉那一幕：三拍，第二拍才是重点

`illusion` 的三拍是：**① 哪个大 → ② 一样大（橙圈严格重合，只给证据）
→ ③ 知道了，再看一眼 —— 还是不一样。**

第三拍是全场的枢纽：**知道答案，修不好它**。所以把同一张图原样再放一次，
让他当着「已知」的面再失败一次，然后才接 Eagleman 的
"the first lesson about trusting your senses is: don't."，
顺势推出「所以要测量」。

（这一幕的位置：在 Eagleman 之后、脑电之前。用户确认过 ——
错觉最独特的价值就是「知道真相也无法消除」，那正好是「为什么要用仪器」的论证。
盲点讲的是另一件事：无意识的填充。）

### ⚠️ 屏幕上不要写「怎么操作」的提示

讲者自己知道按 → 翻页就行，**学生不需要知道**，而且提前告诉他们
「点一个你觉得对的」会毁掉现场的新鲜感。所以 demo 里刻意不写这类文字，
由你口头说。已经清掉的有：翻页提示、贴标签的做法说明、
「拖拽旋转滚轮缩放」、「点一个你觉得对的」等。
**加新场景时请不要把这些加回来。**

（实验本身的步骤说明要保留 —— 「1. 闭上左眼」那种是内容，不是操作提示。）

### ⚠️ 场景 CSS 是全局的 —— 新类的名字一定要带场景前缀

`PERCEPTION.css()` 把样式注入到 `<head>`，**不是** scoped 的。
所以两个场景里如果出现同名类，样式会互相污染。
真实踩过的坑：曾经有个场景的播放三角用了 `.tri`，而树倒场景里的
「三张卡片一行」也叫 `.tri`（带 `padding: 1vw 2vw`）——
结果播放三角被撑到 0 宽，整个按钮变成一个纯白圆点，排查了很久。
（那个场景后来删了，但坑还在。）

规则：**每个场景自己的类名，一律加场景前缀**（`.mp-play`、`.tag-ghost`、
`.cl-…`、`.aw-…`），只有在明确要复用设计系统里的通用类时才用裸名
（`.card`、`.btn`、`.pill`、`.anim`）。改完可以用下面这段快速查重名：

```bash
cd assets/demos/perception && python3 - <<'PY'
import re, glob, collections
pat = re.compile(r"PERCEPTION\.css\(\s*'([^']+)'\s*,\s*`(.*?)`\s*\)", re.S)
owner = collections.defaultdict(set)
for f in sorted(glob.glob('s*.js')):
    m = pat.search(open(f).read())
    css = re.sub(r'/\*.*?\*/', '', m.group(2), flags=re.S)
    for cls in re.findall(r'\.([a-zA-Z][\w-]*)', css):
        owner[cls].add(m.group(1))
for c, k in sorted(owner.items()):
    if len(k) > 1: print(f'.{c}  <-  {", ".join(sorted(k))}')
PY
```

（重名不一定是错——`.card`、`.ico`、`.on` 这类复用是故意的。
要看的是「某个场景新造了一个通用名的类」。）

## 技术说明

- 纯原生 JS，无依赖、无构建、无 CDN，离线可用。
- 字体走系统栈（PingFang SC / 微软雅黑 / Noto Sans SC）。
- **幻肢痛那一幕的人体图是 NASA 先驱者号镀金铝板的人像线描**（公有领域，
  无需署名）。数据在 `figure-art.js`。原图是全身正面裸像，这里**截到腰部以上**
  （高中场合不合适），并且把高抬的那条手臂在下层**裁掉、再用虚线描一遍** ——
  那个虚线手臂就是幻肢本身。手臂的范围是实测出来的：y<435 时身体轮廓的
  最左侧都在 x<150，那之外就是这条手臂。
  找图的顺序值得记一笔：达芬奇那类解剖素描在 Commons 上没有矢量版，
  Gray 解剖学图谱 139 张里没有全身图，最后是 NIH BioArt 的搜索结果里
  翻到这条线索的。
- **大脑用的是 Gray's Anatomy 的矢量线稿**，不是画出来的：
  公有领域（PD Mark 1.0），原图是 1918 年 Gray 解剖学第 728 图，
  由 Wikimedia Commons 用户 Mysid 矢量化。数据放在 `brain-art.js`，
  几何一点没改，只做了两件事：把原图的四色分区改成透明的可点击脑叶、
  把线条上色成 `--brain-ink`。
  **为什么不再自己画**：我先后试过四轮程序生成脑回 ——
  一排行波（像等高线/木纹）、沿方向场积分的流线（频率低是顺毛、
  频率高是树根）、等值线配 6 条正弦（围着峰绕成同心环，又变回等高线）、
  等值线配 18 条宽带正弦（最接近，但还是「像」而不是「是」）。
  手绘解剖图生成不出来，这条路一开始就不该走。
- 脑叶做成**透明的可点击区域**（`pointer-events:all`，因为 `fill:none`
  的元素默认不接指针），画在线稿**下面** —— 于是高亮时蓝色是
  「从褶皱下面透出来」的，而不是盖上去一块贴纸。
- 两个图上没有、但讲稿要用的区域是补出来的：**前额叶**用 `clipPath`
  把额叶切一刀（裁剪，不是重画）；**边缘叶**是内侧面结构、外侧观看不见，
  用虚线 C 带表示 —— 原图本来就用虚线画被遮住的部位，是同一套语言。
  顺便还能讲一句「情绪的核心结构在大脑内侧面，从外面看不见」。

### 想加更多「先猜一猜」

`quiz.js` 是个通用组件，加一屏只要两步：

```js
function (ctx) {
  ctx.set(QUIZ.html({
    q: '问题',
    options: ['选项一', '选项二', '选项三'],
    answer: 1,                 // 哪一个是「结果」，会打勾
    note: '揭晓之后补一句。'
  }));
  QUIZ.mount(ctx, { answer: 1 });
}
```

`ctx.holdNext()` 是配套的机制：讲者如果没点选项、直接按 →，
第一次只揭晓、不翻页；再按才走。这一条对现场很重要 ——
否则一紧张按快了，答案还没出来就翻过去了。
