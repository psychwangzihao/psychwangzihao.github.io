## 哪里需要动手

1. **盲点**（`blindspot`）—— 前一屏用滑杆把蓝点推到消失。**十字钉死在左边，只有蓝点动**；
   蓝点位置跨屏保持，所以换底色（白 / 绿 / 黄）时不会跳回原点。本幕**禁用点击翻页**。
2. **色的三种机器**（`color`）—— 二色视是**真的算出来的**（二色视矩阵在 sRGB 空间里过一遍），
   不是找来的插图。

翻页笔：**↑↓ / →← / PageUp / PageDown / 空格 一律翻一页**（先逐行露字，露完才翻屏）；
`[` `]` 换幕。⚠️ 这个键位是**为翻页笔定的** —— 很多翻页笔的两个按键发的就是 ↑/↓，
早先版本里 ↑↓ 是「换场景」，一按就整幕跳过去、`.step` 逐行揭露全被跳过。

## 台上要守住的两条

- **四色视那个轮子是形象化写法。** 外圈叠了一层更细的色相带，读起来是「多一维」；
  四维色觉没法在 RGB 屏幕上还原。**不说这一点就成了假演示。**
- **盲点不能说「大脑把洞补上了」。** 填充（filling-in）至今是争议问题，近年最仔细的
  fMRI 工作发现早期视觉皮层反映的是**输入的缺席**。准确的说法是「那个洞不在经验里」。

## 与屏幕尺寸有关的

字号是 `clamp(下限, min(vw, vh), 上限)` —— **取 vw 和 vh 里小的那个**。
`vw` 管「屏幕越宽字越大」，`vh` 管「又宽又矮的长条屏别把字涨到放不下」。
16:9 的普通投影仪上 `vw` 项胜出，和改造之前完全一致；更宽的屏才变大。
实测 1920×1080 / 2560×1080 / 3840×1080 / 3840×2160 / 1366×768 / 1280×800 六种尺寸，**没有一屏溢出**。

盲点的底板是 `width:100vw`，任何比例都左右贴边。注意：**别再给它补
`margin-left:calc(50% - 50vw)`** —— `.stack` 本来就居中、底板又比它宽，浏览器已经把它
居中到视口了，那一句会多减一份、把十字切到屏幕外。

## 引擎

`core.js`（场景机）+ `viz.js`（现场画图：电磁波谱、色轮、二色视模拟、四色视）。
无依赖，纯原生 JS。**文件名不决定顺序，`index.html` 里 script 标签的先后才是顺序。**

`core.js` 有两处对原版（`../perception/`）的修补：

1. `ctx.soon` 里那个 `requestAnimationFrame` 原来没登记进清理表，快速连翻时会在场景
   已换掉之后跑一帧、报 `Cannot read properties of null`。
2. **键盘键位**（见上）。原版 ↑↓ 是换场景，对翻页笔是灾难。
