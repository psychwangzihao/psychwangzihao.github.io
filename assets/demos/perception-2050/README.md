# 感知 / Perception

2050「未来感知的形质」恳谈会的分享用演示。**11 幕、31 个状态。**

不是幻灯片，也不是一件作品 —— 它是分享的辅助：屏幕上只放事实和能当场做的演示，
解释由讲者说。所以这里的文字极少，而且**不出现第一/第二人称、不出现祈使句**。

- 线上地址：<https://psychwangzihao.github.io/assets/demos/perception-2050/>

## 结构

## 三处必须用浏览器

1. **盲点**（`blindspot`）—— 滑杆调两点间距，圆点会在某个位置消失。本幕禁用点击翻页。
2. **现场报数**（`imagine`）—— 数字键 1–5 计数、0 撤销、R 清空。
   ⚠️ 这一屏会接管键盘，离开时必须放掉 `PERCEPTION.keyHook`（代码里已经做了）。
3. **色的三种机器**（`color`）—— 二色视是**真的算出来的**（二色视矩阵在 sRGB 空间里过一遍）。

## 台上的两条纪律

- **四色视那个轮子是形象化写法。** 外圈叠了一层更细的色相带，读起来是「多一维」；
  四维色觉没法在 RGB 屏幕上还原。**不说这一点就成了假演示。**
- **盲点不能说「大脑把洞补上了」。** 填充（filling-in）至今是争议问题，近年最仔细的
  fMRI 工作发现早期视觉皮层反映的是**输入的缺席**。准确的说法是「那个洞不在经验里」。

## 引擎

`core.js`（场景机）+ `viz.js`（现场画图：电磁波谱、色轮、二色视模拟、四色视）。
无依赖，纯原生 JS。**文件名不决定顺序，`index.html` 里 script 标签的先后才是顺序。**

`core.js` 有一处对原版（`../perception/`）的修补：`ctx.soon` 里那个
`requestAnimationFrame` 原来没登记进清理表，快速连翻时会在场景已换掉之后
跑一帧、报 `Cannot read properties of null`。
